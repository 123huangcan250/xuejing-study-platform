# 学境 · AI 课程学习与游戏化复习平台

本地 Web 应用（浏览器访问）+ 任意 OpenAI 兼容云端 API。以 **「一门课程 = 一个冒险世界」** 为中心，用同一套数据贯穿阅读、非线性探索、闪卡复习与游戏化激励。

> 当前进度：**Phase 1 完成，Phase 2 完成了 FSRS 闪卡部分**；另外已做：清华大模型接入、文档翻译、换肤与字体（见文末路线图）。尚未做：题库与出题、真题仿真。

## 快速开始

需要：Python 3.11+、Node.js 20+（有 [uv](https://github.com/astral-sh/uv) 会更快）。

```powershell
.\scripts\dev.ps1
```

首次运行会自动装依赖。启动后打开 <http://localhost:3400> → 右上角「设置」填 Base URL、API Key 和各档模型（有 OpenAI / DeepSeek / OpenRouter / 硅基流动 / Gemini 预设）→ 回首页新建课程 → 上传 PDF。

- 后端：<http://127.0.0.1:8400>（接口文档 `/docs`）
- 所有数据都在 `backend/data/`（SQLite `app.db` + `chroma/` 向量库 + `uploads/` 原文件），**备份就复制这个文件夹**
- API Key 只存在本机 `app.db` 里，接口返回时会打码

| 游戏化 | 统一事件总线 `GamificationService`：XP / 等级 / 金币、每日目标（20 XP）点亮连胜、GitHub 风格热力图、11 个成就、升级与成就动效（可静音）、伙伴成长形态与“犯困”提醒 |

### 防“伪游戏化”规则

- 只有主动行为得 XP：原文提问 6、追问 4、汇总提问 8、复习**到期**卡 1~3（提前刷卡 0 XP）
- 同类事件有每日 XP 上限，刷同一个动作收益会归零
- 同一个问答节点重新生成不重复给奖励；断签不扣分

## 内存占用

实测（Windows，空闲时）：

| 组成 | 内存 |
|---|---|
| 后端（Python） | 约 200 MB（模块导入约 110 MB；第一次检索会再加载 jieba 词典约 70 MB） |
| 前端 · **生产模式**（`run.ps1` / `remote.ps1`） | 约 80 MB |
| 前端 · **开发模式**（`dev.ps1`） | **约 1.6 GB** |
| 清华 token 自动更新时的无头 Chrome | 约 530 MB，只存在一两分钟，关闭后无残留 |

所以**日常使用请用 `.\scripts\run.ps1`（生产模式），总共约 300 MB**；只有改代码、需要热更新时才用 `dev.ps1`。向量检索（ChromaDB）只有在设置里配置了向量模型才会加载，没配置就不占内存。

## 数据备份

数据库（课程、切块、译文、知识图谱、闪卡、学习记录、设置）每次启动时若距上一份备份超过 20 小时就自动备份一次，运行期间每小时检查一次，只留最近 10 份，存放在 `backend/data/backups/`（已被 git 忽略）。用 SQLite 在线备份接口，不用停服务，写完会做完整性校验。

- 手动备份：`POST /api/backups`；备份列表：`GET /api/backups`
- 恢复：停掉程序，把想要的 `app-*.db` 复制成 `backend/data/app.db`（同时删掉 `app.db-wal`、`app.db-shm`），再启动
- 上传的原文件在 `data/uploads/`，不在自动备份里（它们本来就是你电脑里的原件）
- 想关掉自动备份：环境变量 `ALP_DISABLE_BACKUP=1`

## 资料种类、知识梳理、思维导图、试卷考点

上传资料时选择种类（之后可在资料库里随时改，改种类会清掉按旧种类生成的结果）：

| 种类 | 用途 |
|---|---|
| **课件** | 生成知识梳理和思维导图；之前上传的资料默认都算课件 |
| **试卷** | 拆题、识别考点和能力层级、对应到课件知识点 |
| **参考资料** | 可检索、可翻译，但不参与知识梳理 |

- **知识梳理**（「知识梳理」页）：把每份课件提炼成「课件 → 小节 → 知识点」，每个知识点带要点、重要度（★）和出处页码。大文件按页分窗口并发提炼；内容没变的课件再次梳理会直接跳过；一份课件失败不会破坏已有结果。
- **思维导图**：同一份数据的导图视图，可折叠、可按课件筛选、可「只看考点」；点节点看详情，可跳到原文页、问 AI、做成闪卡。另有大纲视图（可搜索），可导出 Markdown。
- **试卷考点**（「试卷考点」页）：试卷拆成一道道题，AI 给出考点、布鲁姆能力层级（记忆 / 理解 / 应用 / 分析 / 综合）、难度，并对应到课件知识点。模型只能从知识点目录里选编号，编造的编号会被过滤；对不上课件的题如实显示「没有找到对应的知识点」。
- **课件里的考点提示**：读课件时，相关页面上方会出现「📌 考点 2025期末试卷 Q1 · 某知识点」，点开可看题目。
- 需要先对课件做知识梳理，才能把试卷考点对应到课件。会调用模型（用「翻译」/「轻量快速」/「强推理」档的第一个可用模型）。

## 远程访问（Tailscale）

在图书馆等地方，用浏览器访问宿舍电脑上的这套应用。**页面经隧道显示，资料、数据库、API 密钥、清华登录状态都留在宿舍电脑上。**

**一次性准备**
1. 宿舍电脑和你远程用的设备都装 [Tailscale](https://tailscale.com/download)，登录**同一个账号**。
2. 在 Tailscale 管理后台（login.tailscale.com/admin/dns）打开 **HTTPS Certificates**（Serve 需要）。
3. 运行 `.\scripts\remote.ps1`。首次会在终端引导你设置**访问密码**（无回显输入，至少 10 位，只存 scrypt 哈希）。

**使用**：`.\scripts\remote.ps1` 会构建并以生产模式启动前后端、开启 Tailscale Serve、期间阻止电脑休眠，并打印形如 `https://电脑名.xxxx.ts.net/` 的地址。远程设备打开它，输入访问密码即可。`Ctrl+C` 或 `.\scripts\remote.ps1 -Stop` 会撤销远程入口并停止服务。需要关闭 dev.ps1 再运行（端口相同）。

**安全设计**
- 前后端都只监听 `127.0.0.1`（之前前端开发服务器对局域网开放，已修复）；唯一的远程入口是 Tailscale Serve——只有你 Tailscale 账号下的设备能连，并且走 HTTPS。
- 前端把 `/api` 转发给后端（单一入口），后端和它的密钥永远不直接对外。
- **没设访问密码就拒绝一切远程访问**；设了密码后**所有访问（包括本机）都要先登录**，不靠来源地址判断，避免被伪造。登录后发 HttpOnly + SameSite 的签名 Cookie（30 天），写请求检查同源。
- 密码只能在本机命令行设置（`python -m app.access_cli set | status | logout-all | disable`），没有任何接口能设置或修改；改密码或「登出所有设备」会让已登录的设备立即失效。
- 登录失败限速：同一来源连续失败 5 次起锁定 5、10、20、40 分钟…（最长 1 小时），另有全局兜底。

**要注意**
- **清华 token**：约 4.5 小时自动更新一次，需要二次验证时验证窗口**只会出现在宿舍电脑上**，你人在外面够不着。出门前确认 token 还剩足够时间（脚本启动时会显示），或先在本机更新一次。
- 宿舍电脑必须开机、联网（脚本运行期间不会休眠，但不能关机或断网）。
- 用单独的 PowerShell 窗口运行 `remote.ps1`，不要放在会随编辑器 / AI 会话关闭的终端里；关掉那个窗口就等于关闭远程入口。
- 生产构建在 `frontend\.next-prod`，与开发服务器的 `.next` 分开（以前共用时，开发服务器一启动就会弄坏生产构建，导致远程入口被关闭）。启动、停止及停止原因记录在 `backend\data\remote.log`。
- 图书馆的公共电脑通常不能装 Tailscale；可以用手机上的 Tailscale App 登录同一账号，或在自己的笔记本上使用。
- 本机日常使用不变：dev.ps1 + `http://localhost:3400`，没设访问密码时无需登录。

## 清华云盘读取（分享链接）

资料库页的「清华云盘」区域：粘贴文件夹或单个文件的分享链接（有无提取码都行）→ 浏览并勾选文件 → 导入。

- **只读、不需要清华账号**：只用分享链接本身的权限。只允许 `cloud.tsinghua.edu.cn`（https），重定向的每一跳都检查域名，防止被诱导去访问其他站点或内网。
- **原文件不存本机**：导入时只保存解析出的文字块和检索索引（检索、翻译、知识梳理必需的小文本）；原文件只在临时缓存里（`backend/data/cloud-cache/`，有大小上限，**每次启动和退出都清空**）。阅读、导出时缓存里没有，就自动从云盘取回。链接失效或断网时，已导入的文字仍可检索和阅读文字块，但打开原 PDF / 导出会失败。
- **提取码**：只以 Windows DPAPI 密文保存（`data/secure/cloud_<id>.dpapi`），不进数据库、日志和接口返回；提取码变了会提示重新输入。
- **同步**：再次浏览会标出「新 / 已导入 / 云盘有更新」；有更新的文件只有明确选择才会替换（替换会丢掉旧资料上的译文和知识梳理）。删除来源会连同导入的资料一起删除，不影响云盘里的文件。
- 单文件上限 300 MB，一个分享最多 2000 个文件、6 层目录。

## 文档翻译（英文资料 → 中文）

支持 **PDF、Word（.docx）、PPT（.pptx）、Markdown、TXT**（DOCX / PPTX 现在也能上传、检索、阅读）。

- **读到哪译到哪**：阅读器上方切换「原文 / 对照 / 译文」。选「对照」或「译文」后，当前页和前后页会自动翻译并缓存（按文字块存库，换页、刷新、重启都不重复调用模型）；也可以点「翻译全文」。
- **划词翻译**：选中任意文字，工具条第一个按钮就是「翻译」，可复制或直接做成闪卡。
- **术语一致**：专业术语首次出现时括号附英文原词（如「潮流计算（power flow）」），整份文档的译名保持一致；公式、符号、数字、单位原样保留。
- **导出**：DOCX / PPTX 导出「中文版」（保留原格式）或「中英对照版」；PDF 导出「中文版 PDF」（在原页面上把英文替换为中文，保留图表和版式，尽力而为——文字放不下时会自动缩小字号）；所有格式都可导出中英对照 Markdown。
- **模型**：设置页有独立的「翻译档」（留空则依次使用「轻量快速」「强推理」档）。某个模型接连失败会被冷却一段时间，自动换下一个。翻译推荐选响应快的非推理模型。

## 清华大学大模型服务

设置页把「轻量快速档 / 强推理档」的服务商选成**清华大模型**（或点预设「清华大模型」），可选模型：
`DeepSeek-V4.1-Flash`、`DeepSeek-R1-W8A8`、`qwen3.8-27b`（2026-11-12 实测可用；旧文档里的 `DeepSeek-R1-671B` / `DeepSeek-R1-32B` 当日返回“模型不存在”，未列出）。设置页的「检测模型可用性」会对三个模型各做一次最小真实调用（消耗少量学校额度）。

**首次授权**（二选一）：

```powershell
.\scripts\tsinghua-setup.ps1
```

在终端里输入账号、无回显输入密码，用当前 Windows 用户 DPAPI 加密保存；或者不存密码，在设置页点「打开登录窗口」亲自登录。改密码后再运行一次 `tsinghua-setup.ps1` 即可（同时解除“暂停自动提交密码”）。其他命令：`tsinghua-setup.ps1 status | login | logout | clear`。

**工作方式**

- 后端启动时从 `backend/data/secure/` 恢复 token 记录和浏览器登录状态；token 仍有效就只排程、不开浏览器。
- 按文档“每次登录约 5 小时有效”保守处理：签发后约 4.5 小时重新认证；启动时 token 已用过一段时间会按剩余时间提前。
- 重新认证时用本机 Chrome/Edge 的独立无头会话：先丢弃模型站点自己的 Cookie/localStorage、保留统一认证会话，能静默完成就不提交密码；需要时只向**严格确认为 `https://id.tsinghua.edu.cn` 且表单结构和提交目标都符合预期**的页面自动填写。
- 遇到图形验证码 / 二次验证（短信、企业微信）会打开可见窗口交给你完成，不尝试绕过；没完成就不再反复弹窗，设置页可再点「打开登录窗口」。
- 失败按 5/10/20/40/60 分钟退避；旧 token 未过期时继续用；读到和旧的一样的 token 不算更新成功。自动提交密码未通过后会暂停自动提交，直到你更新凭据，避免锁号。
- 上游返回 401 会作废当前 token 并立即重新认证；HTTP 200 但正文是 `{"message":"模型不存在"}`、网页、流内 `error`、开头即错误文本、无结束标记等都按失败处理。
- 项目退出时停止后台任务并关闭浏览器进程；不创建任何系统计划任务。
- 等响应头或两段数据之间超过 90 秒没有数据即判定失败（设置页的检测为 60 秒、三个模型并发），不会把界面卡住。
- `DeepSeek-R1-W8A8` 实测把推理过程直接放在正文里、只以 `</think>` 结尾（没有 `<think>` 开头，`reasoning_content` 为空）：对 R1 类模型会先缓冲到 `</think>` 再输出回答。

**2026-11-19 真实调用记录**：账号密码自动提交后清华要求二次验证，用户在弹出窗口完成后成功取得 token；重启后从加密存储恢复、未开浏览器，下次更新排在签发后 4.5 小时。检测结果：R1-W8A8 正常（约 5 秒）、qwen3.8-27b 正常但慢（约 46 秒）、V4.1-Flash 当时先是长时间无响应、随后返回 HTTP 429（上游限流）。模型供应会变，请以设置页检测结果为准。
- 账号密码、token、浏览器状态都只以 DPAPI 密文存在 `backend/data/secure/*.dpapi`（非 Windows 用系统 keyring），不进入配置、日志（有脱敏过滤器）、命令行参数或仓库。

## 与原方案的差异

- **UI 组件**：没有用 shadcn/ui CLI，用 Tailwind 手写了少量基础组件（`components/ui.tsx`），减少依赖。
